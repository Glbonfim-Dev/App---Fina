Termos de Uso do Fina

Versão do modelo: 28 de setembro de 2026.

1. O serviço

O Fina é uma ferramenta de organização financeira pessoal. As informações exibidas são calculadas a partir dos dados que você mesmo cadastra e não constituem recomendação financeira, contábil ou de investimentos.

2. Sua conta

Você é responsável por manter sua senha em sigilo e pela veracidade dos dados cadastrados. É preciso ter 18 anos ou mais para criar uma conta.

3. Uso adequado

É proibido usar o app para fins ilícitos ou tentar acessar dados de outros usuários.

4. Disponibilidade

Trabalhamos para manter o serviço disponível, mas ele pode passar por interrupções para manutenção. Recomendamos exportar seus dados periodicamente.

5. Encerramento

Você pode excluir sua conta a qualquer momento em Perfil > Excluir minha conta.

6. Privacidade

O tratamento de dados pessoais segue a nossa Política de Privacidade.

7. Contato

O operador da instância deve publicar aqui seu canal de atendimento. Vulnerabilidades no código-fonte podem ser reportadas de forma privada em GitHub Security Advisories.
